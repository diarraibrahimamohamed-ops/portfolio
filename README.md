# Portfolio — Ibrahima Mohamed Diarra

Portfolio statique basé volontairement sur le design original fourni, avec mise à jour du contenu uniquement.

## Réalisations présentées

- [N3XORA v2.0](https://github.com/diarraibrahimamohamed-ops/nexora_v2) — bioinformatique, docking, HSA, recherche computationnelle.
- [Rouleau / Nova Commerce](https://github.com/diarraibrahimamohamed-ops/rouleau) — e-commerce full-stack Next.js / PostgreSQL / Prisma.
- [ShopFlow](https://github.com/diarraibrahimamohamed-ops/ecommerce) — e-commerce PHP / MySQL avec administration et sécurité applicative.
- [SNSC-MALI / Vaccin Track](https://github.com/diarraibrahimamohamed-ops/SNSC-MALI) — système de suivi vaccinal avec Laravel, Next.js, FastAPI et PostgreSQL.
- [Snake Eyes / AfricaWatch](https://github.com/diarraibrahimamohamed-ops/snake_eyes) — plateforme de cybersécurité, Threat Intelligence, OSINT, SOC, vulnérabilités, Offensive Lab et Security Lab.
- [EMPEREUR v0.19.0](https://github.com/diarraibrahimamohamed-ops/empereur_IA) — agent Linux local à missions persistantes, intelligence projet, control plane REST/WebSocket et interaction vocale contrôlée.

## Fichiers

- `index.html` — contenu et structure du portfolio, six réalisations et architecture des aperçus
- `style.css` — design original conservé
- `script.js` — interactions et animations originales, texte de rotation mis à jour


### Captures des projets

Le portfolio utilise le dossier `image/` pour les captures locales disponibles. Les projets sans capture fournie (Snake Eyes et EMPEREUR) utilisent uniquement des aperçus fonctionnels construits à partir des fonctionnalités documentées de leurs dépôts, sans inventer de capture d’écran.
